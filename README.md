# Prodeskel Redesign — Agent Brief

Paket ini berisi konteks, arahan desain, struktur halaman, token, komponen, dan rencana implementasi untuk mockup redesign landing page **Prodeskel — Profil Desa dan Kelurahan**.

## Tujuan terdekat

Menyiapkan landing page high-fidelity untuk kebutuhan proposal tender Kemendagri yang dapat ditampilkan pada **Senin, 3 Agustus 2026**.

## Strategi

- Gunakan **NaraUI** sebagai fondasi teknis sementara.
- Tidak perlu melakukan rebrand source code atau nama komponen pada tahap proposal.
- Ubah hanya theme, token warna, tipografi, aset, content, dan layout agar seluruh tampilan terasa sebagai produk Prodeskel/Kemendagri.
- Komponen domain baru langsung menggunakan nama netral atau nama Prodeskel.
- Rebrand package dan komponen NaraUI dilakukan setelah tender disetujui.

## Prinsip utama

> Mengurangi beban visual tanpa mengurangi kedalaman data.

Landing page harus terasa modern, resmi, aktif, dan data-oriented. Tampilan bukan sekadar company profile, tetapi sebuah portal data desa dan kelurahan tingkat nasional.
