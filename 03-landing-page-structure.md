# 03 — Landing Page Structure

## 1. Government utility bar

Isi:

- Kementerian Dalam Negeri Republik Indonesia;
- Direktorat Jenderal Bina Pemerintahan Desa;
- Bantuan;
- Aksesibilitas;
- Bahasa.

Tampilan berupa bar tipis berwarna deep blue.

## 2. Main header

Kiri:

- logo atau lambang;
- wordmark `PRODESKEL`;
- subtitle `Profil Desa dan Kelurahan`.

Navigasi:

- Beranda;
- Data Prodeskel;
- Progres;
- Klasifikasi;
- Publikasi;
- Galeri;
- Panduan.

Kanan:

- pencarian;
- tombol `Masuk Sistem`.

## 3. Hero

Headline:

> Data Desa dan Kelurahan Indonesia

Deskripsi:

> Data potensi, perkembangan, dan profil desa/kelurahan sebagai dasar perencanaan pembangunan yang tepat sasaran dan berkelanjutan.

CTA:

- Jelajahi Data;
- Lihat Progres.

Visual kanan:

- peta Indonesia;
- titik wilayah;
- garis koneksi halus;
- floating stat chips.

## 4. National overview

Empat card:

- Jumlah Desa/Kelurahan;
- Provinsi Terdata;
- Progres Pendataan;
- Tahun Data Aktif.

Tambahkan teks waktu pembaruan.

## 5. Regional exploration

Layout dua kolom:

### Kiri — Jelajahi Data Wilayah

- pencarian wilayah;
- peta Indonesia;
- legenda progres;
- zoom controls;
- hover/click state;
- CTA menuju detail wilayah.

### Kanan — Ringkasan Progres Nasional

- filter top provinsi;
- horizontal progress bars;
- daftar top kabupaten/kota;
- CTA `Lihat Selengkapnya`.

## 6. Data Utama Prodeskel

Enam category cards:

1. Data Dasar Keluarga
2. Potensi Desa/Kelurahan
3. Tingkat Perkembangan
4. Kependudukan
5. Ekonomi & BUMDes
6. Sarana & Prasarana

Setiap card:

- ikon;
- title;
- deskripsi singkat;
- `Lihat Data`.

## 7. Classification and activity

Layout dua kolom.

### Klasifikasi Wilayah

- Swadaya;
- Swakarya;
- Swasembada;
- Tipologi Desa/Kelurahan.

Gunakan donut chart atau progress ring.

### Suara Prodeskel

Bukan chat bubble. Gunakan activity feed:

- pemerintah daerah;
- aktivitas;
- timestamp;
- status badge;
- link lihat semua.

## 8. Information and help

Empat card:

- Pengumuman;
- Publikasi Terbaru;
- Panduan Penggunaan;
- Kontak / Help Center.

## 9. Footer

Isi:

- identitas Prodeskel;
- identitas Kemendagri/Dirjen Bina Pemdes;
- alamat dan kontak;
- tautan cepat;
- kanal sosial;
- copyright;
- versi sistem bila diperlukan.
